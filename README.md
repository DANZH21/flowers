## 🌸 Flower Bot - Telegram Bot для Цветочного Магазина

Полнофункциональный Telegram-бот для управления цветочным магазином на **Go**.

### ✨ Возможности

- 🌸 **Каталог букетов** с фото из S3
- 🛒 **Оформление заказов** с доставкой или самовывозом
- 💳 **Оплата через Kaspi Pay** или наличные
- 🎨 **Кастомные букеты** - пользователи могут заказать свой букет
- ⚙️ **Админ-панель** для управления:
  - Список заказов и их статусы
  - Каталог букетов (добавление, редактирование, удаление)
  - Управление кастомными букетами
  - Настройки магазина
  - Статистика
- ⏲️ **Автоматические таймеры**:
  - Снятие резерва через 30 минут
  - Отмена заказа если чек не загружен за 30 минут
- 📱 **FSM состояния** для удобного взаимодействия пользователей
- 🔐 **Безопасность**: параметризованные SQL запросы, двойное подтверждение для админ действий

### 🔧 Стек

- **Язык**: Go 1.21+
- **Telegram Bot**: `gopkg.in/telebot.v3`
- **База Данных**: PostgreSQL 16 + `pgx/v5`
- **Конфиг**: `.env` через `godotenv`
- **Docker**: Multi-stage build для оптимизации
- **Планировщик**: встроенный `time.AfterFunc`

### 🚀 Установка и запуск

#### 1. Используя Docker Compose (рекомендуется)

```bash
# Клонируем репозиторий
git clone <repo-url>
cd flower-bot

# Создаем .env файл из примера
cp .env.example .env

# Заполняем значения в .env
nano .env
```

**Необходимые переменные в .env:**

```env
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_IDS=123456789,987654321
DATABASE_URL=postgres://flower_user:flower_password@postgres:5432/flower_bot
SHOP_NAME=Flower Shop
SHOP_ADDRESS=Almaty, Kazakhstan
SUPPORT_USER_ID=123456789
KASPI_LINK=https://kaspi.kz/merchant/...
ABOUT_CHANNEL_LINK=https://t.me/flower_channel
```

```bash
# Запускаем Docker Compose
docker-compose up -d

# Проверяем логи
docker-compose logs -f bot
```

#### 2. Локальный запуск

**Требования:**
- Go 1.21+
- PostgreSQL 16+

```bash
# Устанавливаем зависимости
go mod download
go mod tidy

# Создаем .env файл
cp .env.example .env
nano .env

# Запускаем бота
go run main.go
```

### 📖 Использование бота

#### Для клиентов

1. **Нажмите /start** для начала
2. **Выберите букет** из каталога 🌸
3. **Заполните данные**: имя, телефон, адрес (если доставка)
4. **Выберите оплату**: Kaspi Pay или наличные (только для самовывоза)
5. **Если Kaspi Pay**: загрузите чек из мобильного приложения
6. **Ожидайте подтверждения** от администратора ✅

#### Для администраторов

1. **Нажмите /admin** для открытия админ-панели
2. **Управления заказами**:
   - Просмотр активных заказов
   - Подтверждение/отмена заказов
   - Обновление статуса (доставляется/выполнен)
3. **Управление каталогом**:
   - Добавление новых букетов
   - Редактирование/удаление букетов
   - Скрытие/показ букетов
4. **Управление кастомными букетами**:
   - Принятие с установкой цены
   - Отклонение запросов
5. **Настройки магазина**:
   - Название, адрес
   - Ссылки на Kaspi Pay и канал
   - ID поддержки
6. **Статистика**:
   - Всего заказов, выполнено, отменено
   - Выручка

### 💾 База данных

Бот автоматически создает все необходимые таблицы при запуске:

- **shop_settings** - настройки магазина
- **users** - пользователи (telegram_id, имя, телефон, админ статус)
- **bouquets** - каталог букетов (с информацией о резерве)
- **orders** - заказы всех типов
- **custom_orders** - кастомные заказы

Все таблицы содержат необходимые индексы для оптимизации.

### 🔐 Безопасность

- ✅ **SQL Injection Protection**: Все запросы параметризованы через pgx
- ✅ **Admin Access Control**: Проверка ADMIN_IDS перед каждым админ действием
- ✅ **Double Confirmation**: Двойное подтверждение для критических операций (оплата, отмена)
- ✅ **Rate Limiting**: Одно заказ в 30 минут для одного пользователя
- ✅ **Graceful Shutdown**: Корректное завершение при получении SIGTERM

### ⏲️ Таймеры и автоматизация

- ⏳ **Резервирование букета**: 30 минут (если не завершен заказ - отмена резерва)
- ⏳ **Дедлайн на чек**: 30 минут (если чек не загружен - отмена заказа, возврат букета)
- 💬 **Уведомления админу**: при новых заказах, получении чеков, кастомных букетах

### 🐛 Troubleshooting

**Ошибка подключения к БД:**
```
DATABASE_URL должна быть в формате:
postgres://user:password@host:port/database
```

**Бот не отвечает:**
```
1. Проверьте TELEGRAM_BOT_TOKEN в .env
2. Убедитесь что токен правильный и не истек
3. Проверьте логи: docker-compose logs bot
```

**Ошибка миграций:**
```
Убедитесь что PostgreSQL запущен и доступен
Проверьте DATABASE_URL и учетные данные
```
