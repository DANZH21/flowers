## 💅 Beauty Salon Bot - Telegram Bot для Салона Красоты

Полнофункциональный Telegram-бот для управления салоном красоты (маникюр, педикюр и т.д.) на **Go**.

### ✨ Возможности

- 💅 **Каталог услуг** - маникюр, педикюр, дизайн ногтей и т.д.
- 📅 **Запись на услуги** - клиенты выбирают дату и время
- 🕐 **Расписание** - гибкое рабочее время, настраивается админом
- 🔔 **Напоминалки** - автоматические уведомления за N часов до записи
- 💳 **Оплата через Kaspi Red** - предоплата (% настраивается админом) или наличные
- 📄 **Система чеков** - клиент загружает скриншот оплаты при необходимости
- ⏲️ **Автоматические таймеры**:
  - Отмена записи если чек не загружен за 30 минут (при Kaspi)
  - Напоминание за настраиваемое количество часов
- ⚙️ **Админ-панель** для управления:
  - Список записей и их статусы
  - Каталог услуг (добавление, редактирование, удаление с длительностью)
  - Расписание работы (время открытия/закрытия)
  - Настройки предоплаты (%)
  - Настройки напоминалки (за сколько часов)
  - Настройки поддержки (ID для уведомлений, Kaspi ссылка, ссылка на чат)
- 📱 **FSM состояния** для удобного взаимодействия пользователей
- 🔐 **Безопасность**: параметризованные SQL запросы

### 🔧 Стек

- **Язык**: Go 1.21+
- **Telegram Bot**: `gopkg.in/telebot.v3`
- **База Данных**: PostgreSQL 16 + `pgx/v5`
- **Облако**: S3 (Scaleway или AWS) для хранения квитанций
- **Конфиг**: `.env` через `godotenv`
- **Docker**: Multi-stage build для оптимизации
- **Планировщик**: встроенный `time.AfterFunc` для напоминаний

### 🚀 Быстрый Старт

#### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/DANZH21/flowers.git
cd flowers
go mod download
```

#### 2. Конфигурация (.env)

```bash
cp .env.example .env
# Заполните .env файл:
# TELEGRAM_BOT_TOKEN=your_token_here
# DATABASE_URL=postgres://user:password@localhost:5432/salon_db
# S3_ACCESS_KEY=your_key
# S3_SECRET_KEY=your_secret
# ...
```

#### 3. Запуск с Docker Compose (рекомендуется)

```bash
docker-compose up -d
# Бот начнет работать в контейнере
```

#### 4. Или запуск локально

```bash
# Убедитесь что PostgreSQL запущен и доступен
go run main.go
```

### 📊 Структура БД

#### Таблицы

- **users** - профили клиентов
- **salon_settings** - настройки салона (время работы, напоминание, предоплата)
- **services** - каталог услуг (маникюр, педикюр и т.д.)
- **appointments** - записи клиентов на услуги

#### Ключевые поля salon_settings

```
salon_name TEXT              -- Название салона
address TEXT                 -- Адрес
schedule_open TEXT           -- Время открытия (10:00)
schedule_close TEXT          -- Время закрытия (20:00)
reminder_hours INT           -- За сколько часов отправлять напоминание (1-24)
prepay_percent INT           -- Процент предоплаты (0-100, 0=отключена)
support_user_id BIGINT       -- ID админа для уведомлений
kaspi_link TEXT              -- Ссылка на оплату Kaspi Red
about_channel_link TEXT      -- Ссылка на чат поддержки
```

### 🎮 Использование

#### Клиент

1. `/start` - главное меню
2. **Записаться** - выбрать услугу → дату → время → ввести данные → выбрать оплату
3. **Мои записи** - просмотр активных записей
4. **О нас** - информация о салоне

#### Администратор

1. `/admin` - админ панель
2. **Записи** - просмотр всех записей
3. **Услуги** - управление каталогом услуг (добавить, редактировать)
4. **Настройки** - конфигурация:
   - Название салона и адрес
   - Рабочее время (время открытия/закрытия)
   - Напоминание (за сколько часов)
   - Предоплата (% от суммы)
   - ID поддержки, Kaspi ссылка

### 🔄 Флоу записи на услугу

```
1. Клиент нажимает "Записаться"
   ↓
2. Выбирает услугу из каталога
   ↓
3. Выбирает дату (7 дней в будущее)
   ↓
4. Выбирает время (в рабочие часы, с интервалом 30 мин)
   ↓
5. Вводит имя
   ↓
6. Вводит номер телефона
   ↓
7. Выбирает способ оплаты:
   - Kaspi Red (если включена предоплата): загружает чек
   - Наличные: подтверждение
   ↓
8. Запись создана! ✅
   - Клиент получает номер записи
   - Админ получает уведомление о новой записи
   - Расписывается напоминание за N часов
```

### ⏰ Напоминания и Таймеры

- **Напоминание о записи**: За N часов до начала (настраивается в админке)
- **Дедлайн чека**: 30 минут на загрузку скриншота при Kaspi (если чек не загружен - запись отменяется автоматически)

### 📲 Интеграции

#### Kaspi Red

- Генерируется платежная ссылка для клиента
- Клиент оплачивает → загружает скриншот в бот
- Скриншот сохраняется в S3
- При отсутствии чека через 30 мин - запись отменяется

#### S3 (Scaleway / AWS)

- Сохранение скриншотов чеков
- Используется для хранения платежных доказательств

#### PostgreSQL

- Все данные хранятся в БД
- Автоматические миграции при старте

### 🔐 Безопасность

- **SQL Injection**: Параметризованные запросы (pgx)
- **Антиспам**: Антиспам для клиентов (не более 1 заказа за 30 мин)
- **Валидация**: Проверка формата номеров телефонов, имен, временных диапазонов
- **Права**: Только админы (из ADMIN_IDS) могут менять настройки
